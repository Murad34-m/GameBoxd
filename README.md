# Gameboxd

Rate, review and track every video game you play. A Letterboxd-style game diary: log games, rate and review them, build lists and browse a catalog of 750+ titles with fixed tags (indie, co-op, open world and more).

**Live site:** https://murad34-m.github.io/GameBoxd/

## Notes
- Single-file site (`index.html`), no build step.
- On GitHub Pages your logs are saved in your own browser (localStorage), so they stay on that device.
